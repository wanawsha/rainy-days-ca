# Rainy Days Project

Rainy Days is a mock e-commerce website for a rain jacket brand. It was created as part of a first-semester project to demonstrate understanding of layout, structure, and responsive design using HTML and CSS.

## Description

This project showcases a multi-page website for an online store selling rain jackets. It focuses on clean design, accessibility, and layout structure. The goal was to build a fully responsive site with consistent styling and intuitive navigation.

Features:

 - Homepage with product highlights

 - Product listing pages for men and women

 - Individual product details (static)

 - Checkout page and confirmation page

 - Responsive layout for mobile and desktop

## Built With

 - HTML
 - CSS
